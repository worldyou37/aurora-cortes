YouTube Shorts

A Aurora usa o login oficial do Google para enviar vídeos ao seu canal.
Verificando…
1. Crie o acesso oficialNo Google Cloud, crie um projeto e ative “YouTube Data API v3”. É como criar uma autorização para este aplicativo poder enviar vídeos ao canal que você escolher.
2. Crie a credencial corretaEm “APIs e serviços → Credenciais”, crie um “ID do cliente OAuth” do tipo App para computador. Não crie uma chave de API para substituir o OAuth.
3. Selecione o arquivo baixadoO Google baixa um arquivo JSON de credenciais. Escolha esse arquivo abaixo — ele pode estar no computador ou no celular. A Aurora envia o arquivo diretamente para o computador que está hospedando o painel.
4. Autorize seu canalDepois de salvar o arquivo, toque em “Autorizar Google”. Uma janela de login do Google vai pedir sua autorização para enviar vídeos ao canal. Essa janela abre no computador que hospeda a Aurora; deixe-o acessível, inclusive quando iniciar a autorização pelo celular.
O que é esse arquivo? Ele identifica o aplicativo perante o Google; não é sua senha. A autorização do canal será feita na página oficial do Google. Projetos novos podem ter limites de visibilidade ou precisar de análise do YouTube antes de publicar vídeos públicos.
Erro 403: access_denied — o app está em fase de testes? No Google Cloud, abra Google Auth Platform → Público-alvo. Em “Usuários de teste”, adicione o mesmo endereço Google que será usado para autorizar o canal e salve. Aguarde alguns minutos e tente “Autorizar Google / testar conexão” novamente, entrando com essa conta. Se você não administra o projeto que gerou o arquivo OAuth, peça ao administrador para adicionar seu endereço. Enquanto o app estiver em teste, a autorização expira após sete dias e pode ser necessário repetir este passo.
Autorização concluída? Se o navegador mostrar “The authentication flow has completed. You may close this window.”, a autorização deu certo: feche essa janela e volte ao painel da Aurora. A conexão será atualizada.

CONTA PROFISSIONAL

Instagram Reels

Use uma conta profissional do Instagram. Neste modo de conexão, ela precisa estar ligada a uma Página do Facebook que você administra.
Verificando…
1. Prepare a contaNo Instagram, confirme que a conta é “Criador” ou “Empresa”. Na Meta Business Suite, vincule-a à Página do Facebook correta e verifique que você tem acesso de administrador.
2. Crie um app MetaCrie um aplicativo no Meta for Developers. Adicione o produto Instagram Graph API / publicação de conteúdo e configure o login usado por sua conta.
3. Autorize e peça as permissõesPara este fluxo com Facebook Login, inclua permissões de leitura da Página e publicação de conteúdo, como instagram_basic, instagram_content_publish, pages_show_list e pages_read_engagement. Os nomes exibidos podem mudar no painel Meta.
4. Gere e copie os dadosAbra o Graph API Explorer, escolha seu app, gere um token de usuário e conceda as permissões indicadas. Consulte a Página autorizada para encontrar instagram_business_account.id; esse é o ID pedido abaixo. Copie o token emitido para essa mesma conta.
Por que pede Página do Facebook? A Aurora usa o fluxo Instagram API com Facebook Login, que associa a conta profissional à Página. A Meta também documenta um fluxo Instagram Login com requisitos diferentes; este app atualmente está preparado para o fluxo com Facebook Login.

TikTok

A conta autoriza a Aurora pelo app de desenvolvedor da TikTok.
Verificando…
1. Crie seu app de desenvolvedorNo TikTok for Developers, crie um app e adicione o produto “Content Posting API”. Ative a opção Direct Post.
2. Solicite acesso para publicarConfigure o escopo video.publish e conclua a revisão solicitada pela TikTok. A aprovação e os requisitos da conta são decididos pela plataforma.
3. Autorize sua própria contaNo app de desenvolvedor, configure o Login Kit e uma URL de retorno HTTPS. Faça login com a conta que publicará e troque o código de autorização por um token de usuário, seguindo o guia oficial. Não use App Secret no lugar do token.
4. Cole o token e testeCole o token de usuário abaixo, salve e toque em “Testar conexão”. O teste consulta as opções de publicação da conta, sem enviar um vídeo.
Por que não existe botão “Entrar com TikTok” aqui? O TikTok exige que o app de desenvolvedor tenha uma URL de retorno HTTPS cadastrada. Como a Aurora roda no seu próprio computador, esta página não recebe essa autorização diretamente. Primeiro conclua o Login Kit no portal TikTok e obtenha o token de usuário. A página aceita o token; ela nunca pede seu App Secret.
Conta de teste: a TikTok restringe a publicação de apps que ainda não passaram pela auditoria. Conteúdo desses apps fica privado até a aprovação. Veja os requisitos atuais de Direct Post.

Usamos o token para consultar a conta e enviar os vídeos. Ele fica no computador da Aurora e não aparece de volta nesta página.
Onde ficam as credenciais?
O arquivo OAuth do YouTube e os tokens ficam guardados no computador que executa a Aurora. Use a Aurora apenas numa rede Wi-Fi de confiança: sem código de acesso, outros aparelhos da mesma rede podem abrir esta página. Não compartilhe tokens, o arquivo OAuth ou o computador com pessoas em quem não confia.

A Aurora testa a autorização, mas não consegue aprovar aplicativos em nome das plataformas. Se um app exigir revisão, complete a revisão no portal oficial antes de ativar a publicação.
